# Globussoft Assignment

## Task 1
Amazon laptop scraper using Python, BeautifulSoup and Pandas.

Features:
- Product Title
- Price
- Rating
- Image URL
- Product URL
- Ad / Organic Result

Output is stored in CSV format with timestamp.

## Task 2
Face Authentication using FastAPI.

Features:
- Face verification
- Similarity score
- Bounding boxes
- Same / Different person prediction
